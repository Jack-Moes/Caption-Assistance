Caption assistance 실행 방법
======================

1. Run-Caption assistance-Local.cmd 파일을 더블클릭합니다.
2. Windows Live Captions 창이 열리면 마이크 사용을 허용합니다.
3. ChatGPT 자동 전송 기능을 사용할 때만 아래 Chrome 확장 프로그램을 설치합니다.

Chrome 확장 프로그램 설치/갱신
-----------------------------

1. Chrome 주소창에 chrome://extensions 를 입력합니다.
2. 오른쪽 위의 개발자 모드를 켭니다.
3. 처음 설치할 때는 "압축해제된 확장 프로그램을 로드합니다"를 누르고
   이 폴더 안의 extension 폴더를 선택합니다.
4. 이미 설치했다면 Caption assistance Bridge 카드의 새로고침 버튼을 누릅니다.
5. 열려 있던 ChatGPT 페이지에서 F5를 한 번 누릅니다.

네트워크/개인정보
-----------------

- 외부 배포 확인 서버로 PC 이름, Windows 사용자명, 로컬 IP, 배포 ID를 보내지 않습니다.
- 앱과 Chrome 확장 프로그램은 이 PC 내부 주소 127.0.0.1:17632로만 통신합니다.
- 실행 허용 로컬 네트워크는 요청한 192.168.5.* 대역입니다.

폴더 설명
---------

- Caption assistance-1.0.2-local : 실제 실행 프로그램 폴더입니다. 삭제하면 실행되지 않습니다.
- extension                : ChatGPT 자동 입력/전송용 Chrome 확장 프로그램입니다.
- local-patch              : 수정 소스와 재빌드 자료입니다. 실행에는 필요 없지만 향후 수정을 위해 보관합니다.
